# Terminology

**Artifact** — A discrete object evaluated by the framework, such as source code, documentation, a dataset, model weights, configuration, an experiment output, a receipt, or a binary.

**Origin classification** — A technical description of how an artifact was produced. It is not an ownership or copyright conclusion.

**Participant** — A human, model, agent, tool, organization, or unknown actor involved in producing or reviewing an artifact.

**Process evidence** — A reference supporting an origin claim, such as a Fabric receipt, prompt record, tool log, validation receipt, commit, or external record.

**Rights basis** — The asserted reason a project believes it can distribute an artifact under stated terms. It may also explicitly state that the basis is unknown and needs review.

**Copyright status** — A conservative project classification of the known state of copyright/authorship analysis. It is not a court determination.

**Third-party material** — Material originating outside the immediate project contribution chain, including upstream source, datasets, documentation, generated material with identifiable upstream lineage, or other licensed works.

**Distribution license** — The license expression the project applies to rights it can lawfully license in the artifact. Prefer SPDX identifiers/expressions when available.

**Provenance validation** — Validation that required evidence and classifications are present and internally consistent. It does not prove non-infringement.

**Release gate** — A policy decision that determines whether an artifact may be released, must be reviewed, or must be rejected based on provenance and rights state.
